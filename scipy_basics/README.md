# SciPy Basics

This project demonstrates the basics of using SciPy for scientific computing in Python. The examples cover constants, optimization, sparse matrices, graph algorithms, and distance calculations.

## Contents

- `scpy_basics.ipynb`: Jupyter notebook with code examples and explanations.

## Topics Covered

- **SciPy Constants**: Accessing physical and mathematical constants.
- **Optimization**: Solving linear and non-linear equations, minimizing functions.
- **Sparse Matrices**: Creating and manipulating sparse data structures.
- **Graph Algorithms**: Connected components, Dijkstra, Floyd-Warshall, Bellman-Ford, depth-first and breadth-first order.
- **Distance Metrics**: Calculating Euclidean, cityblock, cosine, and Hamming distances.

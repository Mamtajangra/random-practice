# Number Guessing Game

This is a simple Python command-line game where you try to guess a randomly generated number between 1 and 100.

## How to Play

1. Run the script:

   ```sh
   python guess.py
   ```

2. Enter your guess when prompted.
3. The program will tell you if you need to guess higher or lower.
4. Keep guessing until you find the correct number!

## File Structure

- `guess.py` — Main game script

## Requirements

- Python 3.x

No external dependencies are required.
